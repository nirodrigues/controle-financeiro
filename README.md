# 💜 Controle Financeiro

Uma aplicação web desenvolvida para facilitar o controle e a organização das finanças pessoais, além de ter me auxiliado a aplicar os conhecimentos na prática.

## ✨ Funcionalidades

- Cadastro de entradas e saídas
- Categorização das transações
- Filtros por período
- Filtro por tipo
- Filtro por categoria
- Cálculo de receitas, despesas e saldo
- Exclusão de transações
- Armazenamento local dos dados
- Personalização do nome do usuário
- Interface responsiva

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
